# IDP Chaperone Dataset
This repository contains summary statistics and curation notes from an ongoing study on intrinsically disordered proteins (IDPs) with potential chaperone-like activity.

## Description
- Sources: UniProt, DisProt, MobiDB, AlphaFold
- Criteria: Disorder content > 0.66 (MobiDB-lite), presence of GO terms related to “chaperone activity”
- Data fields: UniProt ID, Protein Name, Organism, GO Terms, Disorder Percentage
